# 经营概览的演示经营数据（只给本机开发库）

运营端首页“经营概览”的数字都是从数据库现查的。本机开发库里付过款的订单很少，看板几乎是空的。要给人演示看板时，可以用这里的脚本灌一份演示数据，用完再清掉。

**只在本机开发库执行。** 这不是 Flyway 迁移，任何环境都不会自动执行。演示数据会出现在运营端的订单查询、用户查询、机构列表里，不要灌进测试环境或生产库。

## 灌入和清掉

在仓库根目录执行（容器名、用户、库名以本机为准；下面是开发栈的默认容器）：

```bash
docker exec -i homerev-postgres-1 sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -v ON_ERROR_STOP=1' < infra/dev/dashboard-demo/seed.sql
```

```bash
docker exec -i homerev-postgres-1 sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -v ON_ERROR_STOP=1' < infra/dev/dashboard-demo/purge.sql
```

`seed.sql` 会先清掉上一份再重建，可以重复执行。随机种子固定，但时间以执行那一刻为准往前铺，所以隔天再灌，数字会略有不同。

## 灌了什么

| 内容 | 数量 | 标记 |
| --- | --- | --- |
| 客户账号 | 2400 个，注册时间铺在最近 200 天，越近越多；约六成最近 30 天用过 | 登录名 `demo-dash-0001`…，显示名“演示客户…”，没有手机号，口令不可用（登录不了） |
| 经营机构 | 36 家，其中 26 家登记了收款账户，30 家资质已审核 | 机构编码 `DEMO-DASH-01`…，名称以“演示·”开头，子商户号 `19900000xx` 是占位号 |
| 交易订单 | 约 3600 笔，七种来源、九个山东城市，最近 200 天越近越多；约 12% 没付款超时关闭，付了款的约 5% 全额退款、3% 部分退款 | 订单号 `DEMO` 开头；每单一行商品，名称以“演示·”开头 |

这些数据和已有的示例商家、开发账号、端到端测试数据互不相干：演示订单只挂在演示机构和演示客户名下，现有商家的工作台里看不到。

演示订单**没有**微信支付记录，非商城订单的业务单 ID 是随机值，对不上任何报名、预约、课程。所以只用来看汇总数，不要在这些订单上做发货、退款、售后等操作。对账下载按微信支付记录出，不包含演示订单。
