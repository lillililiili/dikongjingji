## 页面结构

页面只允许按以下顺序连续滚动：

1. 固定页头：返回、服务详情、分享。
2. 服务头图与核心信息；服务商行为绿色资质标签加灰字“可服务城市”。
3. “价格与取消”卡：计价方式、影响价格、取消说明三行，服务端没配置的行不出现，三行都没有时整卡隐藏（2026-11-05 画板 InspDetail 确认）。
4. 四个巡检项目。
5. 四步服务流程。
6. 四项交付成果。
7. 三项服务保障。
8. 三条服务说明。
9. 评价摘要、筛选和评价卡片。
10. 固定底栏：客服为次操作，预约服务为唯一主操作。

服务保障只渲染一次；评价“查看全部”只保留一处；底栏不得遮挡正文。

## 数据与交互边界

- 生产环境通过正式目录 DTO 读取服务标题、摘要、封面、价格和巡检项目；development fixture 只供测试和视觉校准，生产页面不得读取。
- 预约动作发出携带 `serviceId` 与 `cityCode` 的类型化意图，由 INS-M-004 创建真实预约；详情页自身不创建订单。
- 客服、分享、查看全部和预约未接入宿主时必须给出明确反馈。
- M02 只补正式目录 API 数据源和详情路由接线，不改变列表页面结构。
