# M03 电力巡检服务详情

## 视觉基线

- 唯一基线：`C:/Users/Admin（无密码）/Downloads/电力巡检服务详情页UI整改与Codex验收板.pdf`
- 目标视口：`941 × 1672` 参考截图，对应移动端 `375–430` CSS 逻辑像素自适应。
- 两张手机截图是同一页面的首屏与下滑状态，不是两个页面。

## 页面结构

页面只允许按以下顺序连续滚动：

1. 固定页头：返回、服务详情、分享。
2. 服务头图与核心信息。
3. 四个巡检项目。
4. 四步服务流程。
5. 四项交付成果。
6. 三项服务保障。
7. 三条服务说明。
8. 评价摘要、筛选和评价卡片。
9. 固定底栏：客服为次操作，预约服务为唯一主操作。

服务保障只渲染一次；评价“查看全部”只保留一处；底栏不得遮挡正文。

## 数据与交互边界

- 本阶段只使用 M03 私有 development fixture，生产环境不得显示参考图中的价格、评分、服务次数和评价数据。
- 预约动作只发出携带 `serviceId` 的类型化意图，不生成订单。
- 客服、分享、查看全部和预约未接入宿主时必须给出明确反馈。
- M02 不在本阶段修改，列表入口联调按用户批准暂缓。
