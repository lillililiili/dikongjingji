# 06｜测试与验收

## 1. 总原则

- 测试必须覆盖真实入口、真实路由和真实 API。
- UI 静态阶段可以使用明确的 development Fixture。
- 生产构建不能引用 Fixture。
- 不得直接写数据库最终状态来代替入口和查询验证。
- Android、iOS 真机不是桌面浏览器模拟。

## 2. 自动化层级

| 层级 | 重点 |
| --- | --- |
| 领域单元测试 | 分类、价格、查询值对象 |
| 前端组件测试 | 两页组件和状态 |
| 服务端单元测试 | 参数校验、排序策略、城市开通 |
| 数据库集成测试 | PostgreSQL/PostGIS、迁移、索引 |
| API 契约测试 | OpenAPI 与实现一致 |
| E2E | 从底部服务真实点击 |
| 真机 | 安全区、键盘、权限、弱网 |
| 视觉回归 | 结构、颜色、间距、溢出 |

## 3. 前端单元/组件测试

最低覆盖：

- Portal DTO 映射。
- 场景点击生成正确的 `categoryCode`。
- `MORE` 生成 `openFilter`。
- 搜索 trim、长度限制、中文输入法组词。
- 城市从共享 store 继承。
- 城市切换清理不适用筛选。
- 价格四种模式。
- 无评分、无服务次数时隐藏。
- 快速切换分类只采用最后响应。
- 分页去重。
- 刷新失败保留旧数据。
- 距离权限拒绝只影响距离排序。
- Hero、图片加载失败降级。
- M01 局部错误状态。
- M02 加载、空、错、超时、无权限、无更多。
- 320宽长中文不竖排。

## 4. 服务端测试

### 单元测试

- `cityCode`、keyword、分类、价格、布尔和分页参数校验。
- 价格模式一致性。
- 综合排序、价格排序和最终 `serviceId` 稳定排序。
- 目录状态过滤。
- 全国默认入口配置与城市覆盖。
- 无位置请求距离排序的拒绝。
- 排序字段白名单。

### PostgreSQL/PostGIS 集成测试

- 空库迁移。
- PostGIS 扩展和 SRID。
- 东营与其他城市隔离。
- 当前城市未开通服务不可见。
- 中文关键词搜索。
- 多筛选组合。
- 价格范围。
- 用户点到覆盖区域的距离。
- GIST 索引可用于空间查询。
- 分页无重复和漏项。
- Redis 缓存命中、版本变化和失效。

## 6. 视觉验收

### 必须保留

- 白底生活服务风。
- 橙色主操作。
- M01 场景宫格、保障条、热门横向卡片和流程。
- M02 分类胶囊、排序条和单列服务卡。
- 底部导航顺序：`首页｜服务｜发现｜商城｜我的`。

### 不允许

- 深色驾驶舱。
- 霓虹科技风。
- 大面积政务蓝。
- 把全部区块改成相同圆角白卡。
- 中文单字竖排。
- 文字/按钮遮挡。
- 图片拉伸。
- 用整页截图覆盖真实组件。

### 截图基准

至少提供：

- Android：360/375 或实际设备宽度。
- iPhone：390 或实际设备宽度。
- 430宽大屏手机。
- 320宽兼容截图或自动化结果。

动态城市、天气、价格、统计和图片不做逐像素判断；结构、间距、字体层级、主色和组件关系必须一致。

## 7. 真机验收

### Android

- 安装、冷启动、热启动。
- 系统返回键。
- 中文键盘。
- 定位允许、拒绝、永久拒绝。
- 网络切换和弱网。
- 长列表滚动。
- 底部导航不遮挡。

### iOS

- TestFlight 或可复验开发安装。
- 顶部刘海/灵动岛安全区。
- 底部手势区。
- 右滑返回。
- 中文键盘。
- 定位权限。
- 前后台切换后状态。

## 8. 性能检查

记录真实数据，不只写目标：

- 首屏接口 P50/P95。
- 首屏可交互时间。
- 列表滚动卡顿情况。
- 图片失败率。
- 首包与巡检分包大小变化。
- 20/50/200 条目录数据下的列表行为。
- 快速切换分类时并发请求数量。

如果没有性能工具，至少提供可重复的手工测量步骤和日志时间点。

## 9. 安全检查

- App 包中无数据库账号、MinIO 密钥、服务器密钥。
- API 使用 HTTPS。
- 排序和筛选服务端白名单。
- 搜索参数化。
- 日志无令牌和精确位置。
- 未下架、未开通、非公开服务不返回。
- 受控图片 URL 不暴露内部存储地址。

## 10. 阶段验收材料

每个验收节点应包含：

- 本阶段文件变更清单。
- 构建、类型检查、格式化和测试命令结果。
- 页面入口和操作步骤。
- Android/iOS 截图或说明为何尚未进入真机阶段。
- 与参考图差异清单。
- 未完成和阻塞事项。

“看起来差不多”“应该可用”不算验收证据。
