# 09｜设计令牌与适配

参考图是视觉事实源。下列令牌用于避免 Codex 自由发挥；如果项目已有已确认令牌，先做映射，不重复建立第二套。

## 1. 颜色

```css
--inspection-primary: #ff6a00;
--inspection-primary-strong: #ff5200;
--inspection-primary-soft: #fff3e8;
--inspection-text-main: #191919;
--inspection-text-secondary: #666b73;
--inspection-text-muted: #969ba3;
--inspection-page-bg: #f7f8fa;
--inspection-card-bg: #ffffff;
--inspection-border: #ebedf0;
--inspection-success: #19b866;
--inspection-blue: #2f80ed;
--inspection-warning: #ffaa00;
--inspection-error: #e5484d;
--inspection-shadow: rgba(0, 0, 0, 0.06);
```

允许 Hero 图片产生自然蓝天背景，不得把页面主题整体改为蓝色。

## 2. 间距

```text
2 / 4 / 8 / 12 / 16 / 20 / 24 / 32 dp
```

主要使用：

- 页面左右：16dp。
- 区块之间：16dp。
- 卡片内：12–16dp。
- 标签之间：6–8dp。
- 320宽页面左右可降至12dp，不降字体。

## 3. 圆角

```text
小标签：6dp
输入框/小卡：10–12dp
大卡：12–16dp
Hero：16dp
胶囊：999dp
```

不得把所有元素统一成同一圆角和阴影。

## 4. 字体

优先使用系统中文字体：

- iOS：PingFang SC。
- Android：系统 sans-serif / Noto Sans CJK。

建议：

```text
页面标题 22sp / 700
Hero 标题 24–28sp / 700
区块标题 18sp / 600
卡片标题 17–18sp / 600
正文 14sp / 400
辅助 12–13sp / 400
价格 20–24sp / 600
```

不得使用装饰性科技字体。

## 5. 触控

- 所有触控区至少 44×44dp。
- 操作按钮视觉高度不低于 40dp，实际触控区补足到44dp。
- 图标按钮必须有可读标签。
- 胶囊间距保证误触率。

## 6. 阴影与边框

- 卡片：`0 2dp 12dp rgba(0,0,0,.06)`。
- 浅色区域优先 1px 边框，不叠加重阴影。
- 禁止发光、霓虹、深色投影。

## 7. 布局

### M01

- 顶部公共区域按安全区自然增高。
- 场景宫格固定四列。
- 保障条横向自适应。
- 热门服务横向滚动。
- 流程四步，图标和文字垂直排列。

### M02

- 搜索和筛选同行。
- 分类单行横向滚动。
- 排序条单行，空间不足时城市保持可点击且标签可缩短。
- 服务列表单列。
- 卡片左图右文。

## 8. 响应式

```text
320：兼容下限
360：Android常见
375：主要基准
390：主流iPhone
412/430：大屏手机
600以上：主体最大600居中
```

- 不依赖固定页面高度。
- 不使用绝对定位拼整页。
- 固定底部导航时，内容底部留 `tabbar + safe-area`。
- 文本放大后容器自动增高。
- 中文长词可正常换行，但不得单字逐行。

## 9. 图片

- Hero 建议 2.7:1。
- 热门卡图 4:3。
- 列表图 4:3。
- 明确宽高占位，避免加载跳动。
- `object-fit: cover`，人工确认主体不被裁掉。
- 加载失败使用语义化占位。
- 图片懒加载。

## 10. 页面状态

- 骨架颜色使用浅灰，不闪烁过强。
- 空状态保持简洁，不添加营销内容。
- 错误状态说明发生什么、能做什么。
- 局部失败优先局部重试。
- 弱网不使用无限转圈。

## 11. 视觉差异记录

Codex 每次视觉验收必须记录：

| 区域 | 参考图 | 实现 | 差异原因 | 是否接受 |
| --- | --- | --- | --- | --- |
| 城市 | 示例东营/济南 | 真实当前城市 | 修正参考冲突 | 是 |
| 分类 | 油气/燃气 | 油气 | 统一编码和展示 | 是 |
| 搜索 | 含服务商 | 服务/场景/关键词 | 本期无服务商搜索 | 是 |
| 数据 | 示例数字 | 真实或隐藏 | 禁止虚假数据 | 是 |
