## 2. 视觉基线

基线是设计画布 v55 的三张画板，390 宽，同一时钟、同一份数据：

| 页面 | 画板 | 比对的状态 |
| --- | --- | --- |
| M05 方案确认 | `PlanConfirm` | 待确认、已勾选、展开 v1、已确认、已过期 |

| M07 交付与验收 | `Delivery` | 待验收、确认面板、已验收 |

像素差异 1.8%–2.1%，主要来自数字的字体回退（画板用 PingFang，H5 走系统字体）。已验收态是 6.9%，因为底部付款按钮属于阶段 C。

和画板不一样、有意保留的地方：

| 页面 | 差异 | 原因 |
| --- | --- | --- |
| M05、M06 | 周期按实际巡检日期算，显示 11/02–01/18，画板写 11/01–01/31 | 修订方案 §8 第 5 项 |

| M07 | 验收后没有付款按钮 | 阶段 C |

## 4. 没有验证的

- **Android 真机**：这台 Mac 没有设备，也没有模拟器。M05–M07 的保存、预览和原生返回都要在真机上确认。修订方案 §10.4 要求顺带复验附件上传。
- **iOS**：L3 不要求。
- **F05–F08 的 `.ps1` 脚本**：这台 Mac 没有 `pwsh`，`verify-visit-flow-smoke.cjs` 覆盖了同样的接口流程。
- **文件保存**：H5 没有保存能力，自动化只验证到生成下载链接。
