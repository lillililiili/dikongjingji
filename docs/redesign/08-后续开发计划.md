## 1. 现在离“能上线试运营”还差什么

一句话：**App 页面基本齐了，但还不能真正运营。** 主要差四样：

1. **没有运营和商家的操作入口。** 内容、直播、商家收款账户、资质审核、城市开通现在都只能靠开发种子和脚本；商家发货、报价、核销只有接口没有页面（概要设计 D8、D11 未定）。
2. **钱还没和真实微信支付走通过。** 交易模块一直对着本机模拟服务，没有和真实的“平台收付通”联调。
3. **图片和数据是示例。** 预览构建用的是原型里的图片和示例商家、商品、活动（D5 未定）；公开构建关着这些页面。
4. **没在真机上验过新页面。** iOS、Android 都没跑过这一轮的新页面，尤其是视频、直播里叠在画面上的按钮和弹幕。

## 3. 建议的顺序

1. **先做 S1**（不需要你定，约 1–2 天）：合流、时区、稳定测试、真机。
2. **同时请你准备 S2 的材料**，尤其是微信支付的商户和密钥、首批资源清单，这两样最花时间。

4. S4、S5 按你定的规则和优先级分批做；不卡决定的 S5-1、S5-2、S5-10（除地图）可以穿插在等待期做。
