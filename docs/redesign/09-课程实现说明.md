## 2. 规则

- 线上课全国可买；一个账号一门课同时只开通一次（单人账号）。已有待付款的再报名直接回到那一张。
- 付款时限 15 分钟；付款到账即开通，有效期从开通算（为空即长期有效）。关闭之后才到账的：没有别的开通时恢复，否则交易模块整笔原路退回。
- 学习：拿一节课的播放地址时记“开始”，播完记“学完”（要先开始过；重看不重复计）。第一次开始一节非试听课时之后不能在线退款，App 在开始前弹窗确认。
- 退款：自己买的、开通着、付款后 7 天内、还没开始学非试听课时 → 全额原路退款，课程关闭。超过 7 天、已开始学：不能在线退，页面说联系客服。附带课程跟商品订单的售后走。
- 附带课程：运营端登记“附带于哪些商品”（只存商品 ID）；这些商品的商城订单完成（确认收货、自动确认收货、自提核销）后给买家开通，同一订单同一门课只开一次，已开通着的跳过。
- 线下班：只是一张卡，指向赛事研学的一个活动（只存活动 ID）；标题、封面、价格、城市取自活动现在的公开信息；活动不存在、没上线、不在当前城市时不显示。报名、收钱都在活动那边。
- 视频地址只给受控 HTTPS 地址；开发环境没有视频存储，预览构建播放 `static/videos/preview/course-*.mp4`（ffmpeg 由画板图片合成，8 秒，无声）。

## 3. 设计假设（默认决定之外，我定的）

1. **线下班按活动报名处理**：研学营、执照培训、入门线下班在课程页显示，点进对应的活动详情（M09）报名，课程模块不收钱；没有对应活动时不显示。卡片的标题、价格取自活动（不另写一份，免得两边不一致）。示例数据里“编程机器人入门课 线下班”挂在一个已下线的活动上，所以不显示。
2. **只有“单人账号”一种规格**：画板 PdSkuCourseFly 的“家庭账号（3 人）”要多人共享开通，没有对应的账号能力，一期不做；运营端也没有多规格。
3. **课程不进购物车、没有数量和配送**：画板沿用了商品弹层的“加入购物车”“数量”“配送方式”，课程不发货、一个账号一份，所以弹层改成“规格 / 开通方式 / 金额”，详情底栏只留“咨询 / 先试听 / 立即报名”。
4. **详情页的“先试听，再决定”只有“课程试听”**：虚拟仿真、到馆体验关联的是商城商品（R6-2），课程没有这层关联。
5. **“相关内容与活动”“买家评价”不显示**：发现页的“内容中提到”按商品等对象反查，没有课程这一类；买家评价整块按画板规则“不足 3 条时隐藏”。
6. **课程列表不做“距离”“筛选”“对比”**：线上课没有地点；课程没有筛选维度定义；对比是商品的（S5-6）。
7. **开始学付费课时前弹窗确认**：画板没有，但这一步会让 7 天退款失效，所以先说清楚。
8. **学习进度只认“播完”**：画板“本课播放完成（模拟）”按钮是原型演示，正式产品由播放结束事件记录。
9. **交易订单的城市记 000000（全国）**：线上课不分城市，交易订单要求城市编码。
10. **附带课程按商品关联**：一期每个商品一种规格，所以按商品而不是规格登记；以后多规格时再细化。附带开通出错只记日志，不影响商城订单完成。
11. **“我的课程”的试听卡**：试听不记录，所以试听卡列的是体验中心“课程试听”对应、我还没开通的课程。

## 4. 没做

课程评价、证书发放、讲师主页、家庭 / 企业多人规格、离线下载、倍速和续播位置、课程分享卡片的“课程”类客服卡片（客服会话的“关于什么”卡片没有课程这一类，咨询直接进与开课机构的会话）、“我的订单”合并页里列课程订单（课程订单在“我的课程”和交易收银台里看）、视频上传与转码（运营端填 https 地址或用素材上传）。
