## 2. 为什么差这么多（根因）

1. **图片被换掉了（最大的一条）。** 画板几乎每张卡都有照片，App 有三类问题：
   - 用纯色块或“浅色底 + 图标”代替照片：发现页、图文详情、专题、四类专业服务目录和详情、服务商主页、需求卡、客服会话里的卡片。原因是我写进计划的两条规则——§23.2 第 3 条、§27.1 第 6 条（“没有授权图片时用纯色块，不用示意照片”）——和用户 2026-11-16 定的“用画板里的图片（只在预览构建用，等有授权图片再换）”冲突，而且是我自己定的。
   - 退回同一张旧图：巡检的预约、提交结果、方案、履约、订单卡都退回旧电塔图 `inspection-hero-v1.png`；巡检详情没封面时写死电力图，所以油气、光伏、园区的头图都是电塔。
   - 配错：体验频道前两张卡互换、场馆头图和“机器人避障闯关”缩略图、行业测绘无人机头图（用了电塔图）。
2. **图标不是画板的。** App 到处用 uni-icons 字体里的近似图标；画板是 24×24、线宽 1.8 的线条 SVG，path 都写在画板 HTML 里。金刚位五个图标形状全错，底栏“发现”、分享、筛选、服务流程、交付成果、保障都不一样。
3. **画板的主题层没做成公共样式。** `light-theme.css` 里有三样东西，每页都用：
   - 二级页头的浅色渐变 `linear-gradient(125deg,#fff9f3,#f3f7ff 65%,#edf9f4)`。现在只有收银台的 `TradePageHeader` 有，其余各页各写白底页头。
   - 卡片阴影加 1px 描边 `0 3px 12px rgba(38,60,101,.06)`；主按钮带投影。
   - “图标方块”：r16、倾斜 -3°、1px 白描边、彩色投影、右上 7px 白高光点，蓝紫橙绿黄五色轮换。App 全是平放的单色方块或圆。

   另外文字色用的是 `#191919` / `#8a8f97`，画板是 `#202c42` / `#738096`。
4. **有几页一直没按新画板重做。**
   - “我的”：还是 I1 的旧设计，有大块“近期巡检订单”和“我的项目 / 设备 / 资质 / 服务支持”四宫格；画板有两张当前事项卡、跨业务的订单五阶段、“我的参与”四项和一列菜单。
   - 巡检详情下半页：数字流程、照片交付物、纯文字保障。四类专业服务详情反而已经照画板做了。
   - 登录页、消息页。
5. **很多区块按“有意不做”跳过了，但前提后来变了。**
   - 商品详情少一半区块：先体验、已选、售后与保障、图文、相关内容；租赁商品还少租赁须知和租赁怎么走。
   - 交易主体只写两行。当初“收款方取决于 C2”，C2 已在 11-18 定了，收银台也已经在显示收款方。
   - 体验、内容、活动、需求、租赁都已上线，“相关内容”“先体验”“发布需求”胶囊这些入口现在有地方可去了。
6. **开发数据缺字段，页面跟着少块。**
   - 巡检除电力外没有价格说明、流程、交付物、保障。
   - 三个商品的参数、清单为 0，商品没有卖点字段，规格名不对。
   - 两个商家没登记收款账户，结果按钮是灰的。
   - 场馆标签里写了“（示例）”，导致折行。
7. **流程上的问题。**
   - 子代理做完页面都给了“390 宽并排对照图”，我只看了报告，没有逐张自己看就提交了。
   - 规则写在记忆里（照抄画板、用画板图片），但我写给子代理的说明和计划文本没带上，有的还写反了。

## 4. 怎么做、怎么验

1. **顺序。** 先 R1、R2、R3（公共层、图片、数据），改完重截全部对照图，差距会先缩小一大截；再按页做 R4；R5 等你定了再排进来。
2. **每一批完成后：**
   - 重新截这一批涉及页面的 390 宽对照图，放 `.planning/style-compare/fix-<批次>/`；
   - 我自己逐张看过才提交，不只看子代理的报告；
   - 一页里还有差异时，在对照图旁边写清是“改不了”还是“有意”。
3. **验证等级。**
   - R1 动了底栏和公共页头，按 L3：320 / 375 / 430 截图、开发版 E2E 全量、公开版构建和防泄漏。
   - R3 改了开发种子，后端测试和冒烟要重跑。
   - 预览图只在预览构建里出现，公开版检查脚本要确认图片不进公开包。
4. **防止再犯。**
