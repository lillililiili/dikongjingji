## 2. 模拟器与运行环境

本轮只使用电脑上已有环境，没有安装或升级任何工具：

- AVD：`LowAltitude_API30_x86`
- ADB 序列号：`emulator-5554`
- 系统：Android 11 / API 30
- ABI：`x86`
- 产品：`sdk_gphone_x86`
- `wm size`：`1080 × 2280`
- 密度：`440 dpi`
- ADB reverse：`8080`、`19000`、`8000`、`8001`
- 调试基座：HBuilderX 5.15 标准基座 `io.dcloud.HBuilder`
- 后端：`http://127.0.0.1:8080` 健康检查 200
- MinIO：`http://127.0.0.1:19000` 健康检查 200

所有 ADB、模拟器和 HBuilder 检测命令均设置为不超过 30 秒，没有再次无限等待。

### HBuilderX 运行修正

项目实际使用 Vue 3，但 `manifest.json` 原先没有显式声明 `vueVersion`。HBuilderX 因此误按 Vue 2 查找不存在的 `@vue/cli-service`，提示“node_modules 缺少编译器模块”。

本轮只补充：

```json
"vueVersion": "3"
```

修正后 HBuilderX 明确输出“编译器版本：5.15（vue3）”“项目 mobile 编译成功”，并成功同步到现有 API 30 模拟器。没有安装依赖、没有修改业务代码。

已有 API 35 模拟器与 HBuilderX 标准基座的原生架构/Android 15 权限不兼容；该尝试按两次失败停止。随后改用电脑上已有的 API 30 x86 AVD完成验收。

## 3. 黄金路径结果

本轮固定测试记录：

- 预约编号：`IR1785253141824d8e57cde`
- 服务单号：`FW202607281553079B27`
- 服务：输电线路无人机巡检
- 地址：`Dongying Test Site`
- 线路长度：`12.5 km`
- 巡检项目：线路本体巡检
- 方案报价：`¥8388`
- 交付文件：现场影像、缺陷清单、巡检点位、巡检报告，共 4 份
- 服务单最终状态：`ACCEPTED`
- 交付最终状态：`ACCEPTED`
- 交付文件关联数：`4`

过程验证：

1. 从公共“服务”入口真实点击进入 M01、M02、M03。
2. 在 INS-M-004 填写地址、长度、日期、巡检项目、联系人和手机号，并勾选协议提交。
3. INS-M-005 从后端恢复预约编号和预约内容。
4. 服务商通过正式 API 发布方案；旧方案自动撤回，新方案由 INS-M-006 读取。
5. 客户在 INS-M-006 勾选协议并确认方案，后端只创建一个服务单。
6. 服务商通过正式 API 安排团队和设备，连续写入开始、进度、完成事件。
7. 现场影像 ZIP、缺陷清单 XLSX、巡检点位 KML、巡检报告 PDF 经上传意图写入 MinIO，并发布交付。
8. INS-M-007 从“安排中”恢复到“报告已交付”。
9. INS-M-008 展示四份文件；单项下载通过受控下载意图并在模拟器保存成功。
10. 客户确认验收后，页面显示“服务已验收/验收已完成”。
11. 强制停止 App 后重开相同服务单，状态和交付文件仍完整恢复。

预约附件是可选项，本次模拟器黄金路径没有调用系统文件选择器；该能力已经由既有文件上传、权限与 MinIO 自动测试覆盖，真实设备的系统选择器和权限弹窗仍需在真机阶段复验。
