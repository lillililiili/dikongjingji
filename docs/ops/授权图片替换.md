# 业务图片和视频的授权与替换

移动端使用 API 响应里的封面、图集、正文配图与播放地址。媒体字段为空时，页面保留图标、空位或未配置提示。订单和预约使用各自保存的快照。修改现有商品的封面不会改写早期订单。

## 开发数据来源

开发数据库的 `R__zz_dev_media.sql` 为巡检、活动、体验项目与场馆、商城商品、课程与课时、发现内容、专业服务和直播间记录媒体引用。首页轮播来自内容模块的 `R__dev_home_carousel.sql`。开发 API 根据 `/api/v1/dev-media/` 路径从受控目录读取文件。视频支持字节范围请求。预览客户端使用收到该业务记录的 API 地址解析开发媒体。

运营在本机工作台新上传的文件由开发对象存储保存，业务表记录文件地址。上传后，运营可以登录预览。App 在读取到已发布的展示图或发现视频时，通过同一开发 API 读取文件。服务端每次检查数据库里是否仍有公开记录使用该文件。定时发布须到生效时间，最后一处公开引用撤回后原地址返回 404。发现视频支持分段播放。付费课时和私有附件使用各自的权限规则。

下列目录存放本机演示文件。上线前，运营需确认正式媒体的授权、使用范围、署名和期限。

| 目录 | 用途 |
| --- | --- |
| `apps/mobile/src/static/images/home/` | 首页轮播示例图片 |
| `apps/mobile/src/static/images/inspection/` 第一层 | 巡检入口、服务封面、交付样例、评价配图和目录类别图标 |
| `apps/mobile/src/static/images/preview/` | 开发资源封面、视频海报、图文配图，也保留早期原型素材 |
| `apps/mobile/src/static/videos/preview/` | 开发课程、发现视频、模拟直播的 MP4 |

[数据库开发种子与文件逐项清单](./授权图片替换-清单.md)记录每个文件的 SQL 来源和对应表，附有实际语句行号。表里的“无开发种子引用”表示文件仍在仓库，可据此复查使用和授权情况。

```sh
node infra/scripts/preview-assets-report.cjs --out docs/ops/授权图片替换-清单.md
node infra/scripts/preview-assets-report.cjs --json
```

工具会检查种子引用的开发文件是否存在。它读取仓库 SQL，线上或本机运营后来录入的数据需在工作台另行核对。

## 替换正式资源

1. 按业务对象登记来源、使用权、授权截止日和署名要求。素材登记参见 [资产清单](../10-asset-manifest.md)。
2. 将已授权文件上传到平台公开展示用的受控存储，取得带有效主机名的 HTTPS 地址。预约附件和交付报告继续使用各自的受限访问流程。
3. 在运营工作台编辑具体活动、场馆、图文、视频、课程或商品。商家可在“我的商品”编辑其封面和图集。批量录入时使用相应模板约定的字段。
4. 从正式目标环境核对接口中的 URL、实际文件响应，以及页面加载、图片裁切和视频播放。商品和服务开放下单前应先更新封面，以便后续订单记录正确快照。

## 公开构建

公开 H5 与 App 的打包排除项见 `apps/mobile/scripts/public-asset-exclusions.json`。开发专属接口只在后端 dev 配置提供，公开客户端也会拒绝开发媒体引用。公开包排除 `static/images/preview`、`static/videos/preview`、三张首页生成图、七张巡检业务样图和六张停用插画。巡检类目图标 `category-thermal.webp` 同时用于公开目录的导航。公开界面另有应用图标和状态插画，授权核查仍应覆盖这些文件。构建说明见 [发布开关](./发布开关.md)。
