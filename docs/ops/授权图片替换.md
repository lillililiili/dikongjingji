## 2. 示例图什么时候让位

规则在每个页面里都一样：**服务端给了图就用服务端的；没给时，只有预览构建、且这个对象是开发种子里的那几个 ID，才用示例图；否则不显示图（灰底或图标）。**

1. 服务端字段（全部字段见清单第二张表）：`activity.cover_url`、`venue.cover_url`、`experience_item.cover_url`、`venue_device.image_url`、`mall_product.cover_url`、`content_article.cover_url`、`content_article.video_url`、`content_topic.cover_url`、`pro_service.cover_url`、`live_room.cover_url` / `replay_url`，以及下单、询价、预约时拍下的快照（`trade_order_line.cover_url`、`mall_inquiry.cover_url`、`rental_inquiry.cover_url`、`inspection_reservation.service_cover_url_snapshot`）。
2. 只认**带主机名的 https 地址**。`pro_service.cover_url`、`live_room.cover_url`、`replay_url` 在库里就有 `CHECK … LIKE 'https://%'`；其余字段库里不拦，但服务端读出时（各模块的 `secureMedia` 一类方法）和 App 的数据层（`/^https:\/\//`）都把非 https 当作没有图。所以填 `http://`、相对路径或内网地址都等于没填，示例图也不会出来（生产没有开发种子）。
3. “受控”指图片放在平台自己的对象存储或 CDN 上（MinIO 公共读桶或 CDN 回源，见 `docs/ops/部署与回滚.md`），地址稳定、不带过期签名，不要直接引用第三方网站的图。
4. 示例图片和示例视频按构建类型启用。即使公开构建打开课程、活动或直播功能并收到开发种子的 ID，缺少授权图片或视频时也只展示缺省状态。服务端提供的正式媒体地址照常使用。功能开关见 `docs/ops/发布开关.md`。
5. 快照字段：订单、询价单创建时会把当时的封面地址拍下来。先换图、再开放下单，免得早期订单的快照里是空的。

## 3. 换图的步骤

**真实数据（推荐，换完不用发版）**

1. 你提供图片（或指定有授权的来源），每张记下：用途（哪个活动 / 商品 / 场馆 / 内容）、来源、授权方式和期限、署名要求。登记表放在 `docs/10-asset-manifest.md` 的“正式产品需要的独立资产”一节，或另建一张授权登记表。
2. 上传到对象存储的公共读桶（只放已授权的展示图；预约附件、交付文件仍在私有桶，不受影响），得到 `https://<静态资源域名>/<路径>`。
3. 在 Web 工作台将受控地址填入对应对象的封面字段。商家也可以在“我的商品”的商品资料中直接上传封面和轮播图。批量录入首批资源时使用 `infra/import-templates/` 对应模板的 `cover_url` 等字段。
4. 用公开构建打开对应页面看一眼：图出来、比例对（各页面按画板的比例裁切，竖图横图都会居中裁）。

**换预览构建里的示例图（演示用）**

预览构建要给别人演示、又不想用原型图时：把同名文件换成有授权的图（文件名、格式不变，尺寸接近原图），重新构建预览版。不要改示例图模块里的 ID 映射，除非开发种子也一起改；改完重新生成清单。
