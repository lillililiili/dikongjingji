# 13｜巡检服务闭环分阶段任务计划

## 1. 加速原则

- 简单、互不依赖的盘点和校验交给轻量子智能体并行执行。
- 核心状态机、公共契约和同一文件的实现保持单线，避免并行冲突返工。
- 每阶段只执行与本闭环有关的最小验证；完整回归集中在联调和交付节点。
- 不把 Android 模拟器当成 iPhone 真机，不把静态截图当成真实 API 验收。

## 2. 任务

### F01｜范围、隔离与基线【已完成】

- PDF 页面和状态盘点。
- 现有代码重叠检查。
- 创建干净 `main` 基线。
- 创建 `codex/inspection-service-flow` 独立工作树。

### F02｜状态机、权限、API、数据库与 MinIO【用户验收点】

- 冻结五个页面、路由和状态转换。
- 完成 OpenAPI 和示例。
- 完成 PostgreSQL 迁移草案。
- 完成 RBAC + 资源归属权限矩阵。
- 完成 MinIO 私有对象与预签名上传/下载规则。

### F03｜后端基础设施

- Java 21 + Spring Boot 3.5 模块化单体。
- 统一错误、认证主体、权限注解和资源授权器。
- PostgreSQL/Flyway、MyBatis-Plus、MinIO、Redis 幂等/限流。
- Docker Compose 开发环境和健康检查。

### F04｜预约与文件上传

- 预约创建/查询、幂等和联系人快照。
- 预约资料上传意图、完成确认和扫描状态。
- INS-M-004、INS-M-005。
- 详情页既有预约按钮最小接线。

### F05｜方案确认【用户验收点】

- 服务商发布方案。
- 客户查看/确认方案。
- 一预约一当前有效方案、版本冲突和过期。
- INS-M-006。

### F06｜服务安排

- 服务单创建。
- 团队/设备安排、进度事件和状态单向推进。
- INS-M-007。

### F07｜报告交付与验收【用户验收点】

- 四类交付文件、ZIP 汇总、单项/全部下载。
- 结果统计、问题摘要、交付发布。
- 验收二次确认和幂等。
- INS-M-008。

### F08｜集成与权限回归

- 空库迁移。
- API 集成、越权、幂等、并发、状态回退和 MinIO 权限测试。
- 移动端单元/组件测试。
- 从真实“服务”入口完成 E2E。

### F09｜真机与交付【用户验收点】

- Android 真机：安全区、键盘、上传下载、权限、弱网。
- iPhone 真机：安全区、返回手势、键盘、上传下载、权限、弱网。
- 相同状态自动截图和视觉差异说明。
- 私有仓库推送、运行说明和验收证据归档。

## 3. 预计工期

在 Android/iPhone、macOS 或云构建账号、开发环境权限均及时可用时：

| 工作 | 预计 |
| --- | --- |
| F02 契约基线 | 0.5 天 |
| F03-F04 基础设施与预约 | 1.5-2 天 |
| F05-F07 方案、履约、交付 | 2-2.5 天 |
| F08 联调与回归 | 1 天 |
| F09 双端真机 | 0.5-1 天 |
| 合计 | 5.5-7 天 |

真机或 Apple 构建资源未提供的等待时间不计入开发工时。
