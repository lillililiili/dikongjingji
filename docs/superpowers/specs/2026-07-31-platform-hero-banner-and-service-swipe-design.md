# 平台主频道 Banner 统一与服务频道滑动设计

## 1. 目标

本次统一首页、服务页各内容频道、发现页和商城页的首屏 Banner，使其复用同一结构、同一尺寸令牌和同一 CTA 按钮样式，同时为服务页内容区增加左右滑动切换频道的能力。

本次只调整首屏 Banner 与服务频道切换交互，不修改订单、预约、详情、支付、退款、接口、路由和底部导航业务。

## 2. 适用范围

统一 Banner 结构覆盖：

- 首页。
- 服务页“我要航拍”。
- 服务页“我要巡检”。
- 服务页“飞行服务”。
- 服务页“机器人服务”。
- 发现页。
- 商城页。

“更多服务”是操作入口，不是内容频道，不配置独立 Banner，也不参与左右滑动。

## 3. 统一 Banner 结构

各页面复用同一个 `PlatformHeroBanner` 公共组件，只通过类型化配置传入各自内容：

1. 左侧主标题。
2. 橙色重点文案。
3. 一段简短说明。
4. 三个绿色勾选卖点。
5. 橙色胶囊 CTA 按钮及箭头。
6. 与该频道业务匹配的独立图片。

视觉结构以用户确认的巡检 Banner 为基准：

- Banner 为横向圆角矩形，控制首屏占用，不恢复为高幅海报。
- 文字位于左侧，图片主体位于右侧。
- 图片左侧增加必要的浅色可读性遮罩，底部使用白色渐隐过渡。
- 主标题和橙色重点文案保持同一行优先；窄屏无法容纳时允许整体自然换行，禁止单字竖排。
- 说明最多两行，卖点固定为一行三个；文案必须为短语，不依赖省略号表达完整含义。
- 各频道保留不同文案和图片，不重复使用同一张城市背景冒充不同频道。
- 375、390、393、430 CSS 逻辑像素宽度下不得横向溢出或遮挡。

## 4. CTA 按钮统一

所有上述 Banner 的主按钮复用同一个组件样式和设计令牌：

- 橙色实心胶囊按钮。
- 高度、水平内边距、圆角、字号、字重和行高完全一致。
- 文案使用白色，并保持满足可读性的对比度。
- 箭头的大小、字重、与文字的间距和垂直对齐完全一致。
- 不因页面文案长短改变按钮高度；允许按钮宽度随文案自然变化。
- 按钮按下态、禁用态和焦点态由公共组件统一处理。

各页面可以使用不同的具体动作文案，但文案必须明确，例如“发布巡检需求”“浏览精选服务”“查看精选商品”，避免“立即体验”等含义不清的表达。

## 5. 服务频道左右滑动

可滑动的内容频道顺序固定为：

```text
我要航拍 ↔ 我要巡检 ↔ 飞行服务 ↔ 机器人服务
```

交互规则：

- 手势监听仅绑定服务频道内容区。
- Header、频道按钮栏和底部导航不响应本次横向切换手势。
- 横向位移达到 50px，且横向位移大于纵向位移的 1.2 倍时，才认定为频道切换。
- 左滑进入下一个内容频道，右滑进入上一个内容频道。
- 一次手势最多切换一个频道。
- 第一项向右滑、最后一项向左滑时保持当前频道，不循环。
- “更多服务”只能点击，不参与滑动。
- 普通上下滚动、卡片点击和按钮点击不得被横向手势拦截。
- 切换继续复用现有 `selectChannel` 流程、异步请求版本保护和各频道滚动位置恢复能力。

手势判断应提取为无 UI 依赖的纯函数，避免将阈值判断散落在页面事件中，并用单元测试覆盖边界。

## 6. 组件与数据边界

实现结构：

- 在平台公共展示层新增一个共享 `PlatformHeroBanner` 视图组件，首页、发现、商城和服务频道直接复用。
- Banner 只负责展示和发出 CTA 事件，不直接拼接路由或请求 API。
- 页面或频道配置负责提供标题、卖点、图片和 CTA 动作。
- “我要巡检”继续保留巡检模块的数据与导航边界，只将 Banner 视图接入公共组件。
- 服务频道选择状态仍由现有服务页容器管理。

不得将首页、发现、商城或巡检的完整页面状态放入 Banner 公共组件。

## 7. 不修改范围

- 不新增或打通预约、订单和支付流程。
- 不改变现有 Header、城市、天气、搜索框和消息按钮逻辑。
- 不改变底部导航顺序和路由。
- 不改服务目录查询、筛选、排序、分页和城市数据。
- 不生成或提交 APK，不启动云打包。
- 不覆盖用户及其他任务的未提交改动。

## 8. 测试与验收

### 单元测试

- 横向位移不足阈值时不切换。
- 纵向滚动占主导时不切换。
- 左滑和右滑分别切换到相邻频道。
- 首尾边界不循环。
- “更多服务”不进入滑动序列。
- 统一 Banner 的必填内容和 CTA 事件正常。

### 页面验证

- 在 393×852 视口依次检查首页、四个服务内容频道、发现和商城。
- Banner 的高度、圆角、内边距、标题字号、说明字号、卖点布局和 CTA 按钮尺寸使用同一设计令牌。
- 所有 CTA 按钮视觉一致，仅文字和动作不同。
- 各频道图片和文案符合各自业务，不重复使用同一背景。
- 服务内容区左右滑动可切换频道，上下滚动和内部点击不误触。
- 375、390、393、430 宽度均无文字裁切、竖排、溢出或底部导航遮挡。

### 工程验证

- 相关测试先出现预期失败，再在实现后通过。
- 移动端完整单元测试通过。
- TypeScript 类型检查通过。
- H5 生产构建通过。
- 使用当前 H5 预览完成自动截图和人工视觉对照。
- 用户确认 H5 效果前不进行云打包。
