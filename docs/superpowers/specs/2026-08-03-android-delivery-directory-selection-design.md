# Android 交付文件目录选择设计

## 1. 目标

在 Android 巡检交付页中，用户每次点击“下载”或“全部下载”时，都先通过系统文件夹选择器决定保存目录。文件必须以服务端建议文件名写入用户选择的目录，不再固定保存到应用私有目录或预设公共目录。

本设计只调整 Android 的保存交互。文件预览、交付权限、短时效下载意图、验收状态和非 Android 平台行为保持不变。

## 2. 已确认决策

- 单个文件每次下载都重新选择文件夹。
- “全部下载”只选择一次文件夹，并保存现有接口返回的一个“服务单号-交付文件.zip”。ZIP 解压后包含全部交付文件。
- 不记录上次选择的目录，不持久化目录授权。
- 同名文件不覆盖，自动使用 `(1)`、`(2)` 等后缀生成新名称。
- 本次只实现和验收 Android；iOS、H5 保持当前行为。
- 使用 Android 系统文件夹选择器，不实现 App 内自定义文件浏览器。

## 3. 当前事实与约束

当前交付页通过真实接口获取单文件或全部文件的短时效下载意图，再使用 `uni.downloadFile` 下载到临时路径。Android 现有保存适配器把临时文件写入固定公共目录 `Download/巡检交付`。

“全部下载”接口 `POST /api/v1/inspection/service-orders/{serviceOrderId}/delivery-files/download-all-intent` 返回一个服务端生成的 ZIP 下载意图。本次不得把它改成四次独立下载，也不得修改 OpenAPI、后端打包规则或对象存储权限。

Android 5.0（API 21）以上使用 Storage Access Framework 的 `ACTION_OPEN_DOCUMENT_TREE` 选择目录。Android 11 以上不能选择内部存储根目录、SD 卡根目录、Download 根目录、`Android/data` 或 `Android/obb`；用户仍可选择或新建允许写入的子文件夹。

## 4. 用户交互

### 4.1 单个文件下载

1. 用户点击交付文件右侧“下载”。
2. 页面立即标记该文件正在处理，并打开 Android 系统文件夹选择器。
3. 用户取消选择时，不请求下载意图、不下载临时文件，页面恢复可操作状态，并轻提示“已取消保存”。
4. 用户确认目录后，客户端获取该文件的短时效下载意图。
5. 客户端下载临时文件，并以服务端 `suggestedFileName` 写入所选目录。
6. 保存成功后提示“文件已保存到所选文件夹”。

### 4.2 全部下载

1. 用户点击“全部下载”。
2. 页面只打开一次系统文件夹选择器。
3. 用户确认目录后，客户端调用现有全部下载意图接口。
4. 客户端下载并保存一个“服务单号-交付文件.zip”。
5. 保存成功后提示“全部文件压缩包已保存”。

### 4.3 保持不变的交互

- PDF、XLSX 等文件的“查看”动作不打开目录选择器。
- KML、现场影像 ZIP 等不支持在线预览的类型继续要求下载后查看。
- 页面返回、客服、验收和订单回流不受影响。
- 目录选择器或写入过程中禁止再次触发单文件或全部下载。

## 5. 架构与组件边界

### 5.1 Android 原生适配器

新增独立的仓库自有 Android UTS 模块，用于交付目录选择和目录 URI 写入。该模块不并入现有预约 PDF 选择器，避免把预约附件读取与交付文件写入混成同一职责。

UTS 模块提供两个稳定能力：

- `pickInspectionDeliveryDirectory`：启动 `ACTION_OPEN_DOCUMENT_TREE`，返回本次选择的目录 URI。
- `saveInspectionDeliveryFile`：在给定目录 URI 下创建唯一名称文件，把临时文件内容写入，并返回最终显示名称。

目录 URI 只在当前下载动作的内存中传递。模块不调用持久化授权接口，不把 URI 写入本地存储、Pinia、路由或日志。

### 5.2 前端数据层适配器

交付数据层提供平台无关的目录选择和文件保存端口：

- Android 调用 UTS 模块。
- iOS、H5 继续使用现有保存回退，不增加目录选择能力。

页面和应用层只接收“已选择目录”“用户取消”或类型化错误，不直接创建 Android `Intent`、`Uri`、`ContentResolver` 或 `DocumentsContract` 对象。

### 5.3 应用动作协调

保存动作在获取短时效下载意图之前选择目录，避免用户取消后仍产生下载请求和临时文件。目录选择成功后，现有流程继续负责：

```text
选择目录
→ 获取受控下载意图
→ 下载到应用临时路径
→ 写入所选目录
→ 清理临时资源
→ 显示结果
```

预览动作不需要目录目标，仍按原路径执行。

## 6. 文件创建与同名处理

选定目录后，UTS 模块通过 `DocumentsContract` 和 `ContentResolver` 创建文档，并使用下载意图返回的 MIME 类型和建议文件名。

创建前查询所选目录已有子项：

- 不存在同名文件时使用原名称。
- 已存在时在扩展名前追加 `(1)`。
- `(1)` 已存在时依次尝试 `(2)`、`(3)`，直到得到未占用名称。
- 不覆盖、删除或修改用户已有文件。

文件名继续执行现有非法字符清理。服务端没有返回有效文件名时，保存动作失败，不由客户端编造无业务含义的名称。

## 7. 写入、清理与并发

- 原生写入在 IO 调度器执行，不阻塞主线程和目录选择器回调。
- 使用固定大小缓冲区从临时文件复制到 `ContentResolver` 输出流。
- 写入成功后关闭输入流、输出流和文件描述符。
- 写入失败时关闭资源，并删除本次新建的不完整文档；清理失败只记录不含目录 URI、文件内容或用户信息的诊断码。
- 页面销毁、Activity 销毁或选择器返回异常时，只完成一次回调并释放监听器。
- 同一时间只允许一个目录选择或文件保存动作，重复点击不创建第二个请求。

## 8. 错误与取消语义

用户取消属于正常结果，不进入红色错误态：

```text
DELIVERY_DIRECTORY_PICKER_CANCELLED
→ 轻提示“已取消保存”
```

其他错误使用稳定编码和用户可理解文案：

- `DELIVERY_DIRECTORY_PICKER_UNAVAILABLE`：当前设备无法打开系统文件夹选择器。
- `DELIVERY_DIRECTORY_NOT_WRITABLE`：该文件夹不允许创建文件，请重新选择。
- `DELIVERY_FILE_NAME_INVALID`：交付文件名称无效。
- `DELIVERY_FILE_SOURCE_UNAVAILABLE`：临时下载文件不可读取。
- `DELIVERY_FILE_WRITE_FAILED`：文件写入失败，请重新选择目录后重试。

网络错误、认证失败、下载意图过期和服务端错误继续由现有 HTTP 与认证恢复机制处理，不改写成存储错误。

## 9. 权限与安全

- 不申请 `MANAGE_EXTERNAL_STORAGE`，不新增全盘文件访问能力。
- 不新增 Android 存储运行时权限。
- 仅访问用户本次明确选择的目录树，并仅创建当前下载动作对应的文件。
- 不持久化目录 URI 或授权，不在日志、埋点、错误文案中输出完整 URI。
- 交付文件仍必须先经过当前用户、对象归属、状态和短时效下载意图校验。
- 不把对象存储内部地址、永久 URL 或令牌写入文件名和日志。

## 10. 测试与验收

### 10.1 自动化测试

- 单文件保存先选择目录，取消时不调用下载意图接口。
- “全部下载”只选择一次目录，并只保存一个 ZIP。
- 查看动作不打开目录选择器。
- 同名文件生成 `(1)`、`(2)`，不覆盖原文件。
- 不可写目录、源文件缺失和写入中断返回稳定错误。
- 写入失败删除本次不完整文档。
- 页面销毁和重复回调不会产生第二次成功或失败结果。
- iOS、H5 回退行为保持不变。

### 10.2 构建与回归

- TypeScript 严格检查。
- UTS Android 编译。
- 移动端全量单元测试。
- H5 与 App-Plus 生产构建。
- `git diff --check` 和任务文件白名单检查。

### 10.3 Android 真机验收

1. 单个文件选择一个新建子目录，确认文件名、大小和内容正确。
2. 再次下载同一文件，确认生成 `(1)` 且原文件未变化。
3. 点击“全部下载”，确认只弹一次选择器并保存一个 ZIP。
4. 取消选择，确认没有新增文件、没有发起下载请求。
5. 选择不可写或系统限制目录，确认有明确恢复提示。
6. 下载完成后从系统文件管理器打开文件，并确认 App 返回交付页后仍可继续操作。

## 11. 修改边界

预计只涉及：

- 交付页面的下载动作协调。
- 交付文件存储适配器和应用动作端口。
- 新 Android UTS 目录选择与文件写入模块。
- 对应前端、UTS 和真机验收测试。

明确不涉及：

- 后端、数据库、OpenAPI、对象存储打包规则。
- 预约附件 PDF 选择器。
- 交付文件预览、发布、验收或审计状态机。
- iOS 原生目录选择。
- 支付、退款、发票或其他资金链路。
- 公共文件管理器、自定义目录浏览页面或长期目录授权。
