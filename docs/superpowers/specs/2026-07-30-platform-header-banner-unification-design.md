# 平台主页面头部与 Banner 统一设计

## 目标

统一首页、服务、发现、商城四个主页面的顶部区域，并收紧发现、商城顶部与 Banner 之间的空白，增加首屏有效内容。

## 已确认视觉规则

- 顶部结构统一为：城市与下拉箭头、城市下方真实天气与天气图标、搜索框、消息图标。
- 首页当前顶部作为结构基准；统一后的尺寸在该基准上整体放大 2%。
- 四页使用同一个共享头部组件和同一套尺寸令牌，避免后续分别修改产生漂移。
- 各页只保留自己的搜索提示、消息行为和未读状态，城市与天气继续使用现有真实数据。
- 发现与商城保留当前 Banner 高度、内部排版、字体和图片比例，不再压缩 Banner。
- 移除 Banner 自身额外的顶部外边距，保留共享头部自然形成的间距；不得通过缩放页面、字体或图标实现。
- 不修改订单、预约、详情、支付、退款、路由和接口。

## 方案选择

采用“共享组件统一”：

1. 扩展现有 `PlatformPageHeader`，支持可选未读角标。
2. 首页、服务、发现、商城全部复用该组件。
3. 统一头部尺寸以首页当前值的 102% 为准，采用同一组 `rpx` 样式。
4. 发现与商城各自保留 Banner 内容组件，只收紧头部与 Banner 之间的间距。

未采用：

- 各页复制同一段 CSS：短期快，但后续容易再次漂移。
- 只给发现和商城加局部覆盖：无法解决首页、服务、发现、商城结构不一致。

## 验收标准

- 430 CSS 逻辑像素宽度下，四页顶部的位置、字号、搜索框高度、图标尺寸和间距一致。
- 城市下方均显示真实天气；无天气数据时不显示假数据。
- 发现、商城 Banner 保持当前高度和内容比例，顶部不再叠加额外外边距。
- 375、390、430 宽度无溢出、遮挡或中文异常换行。
- 首页、服务、发现、商城真机截图完成两轮对比。
- 相关单测先失败后通过；全量测试、类型检查、生产 H5 构建通过。
