# 07｜Codex 逐任务计划

## 1. 执行规则

- 一次只执行一个任务编号。
- 单个任务目标控制在 30–60 分钟；超过 60 分钟必须拆分为 `Txx.a/Txx.b`。
- 任务完成后按 `AGENTS.md` 汇报格式输出。
- 标记“用户验收点”的任务完成后必须停止。
- 用户未回复“验收通过”不得继续。
- 发现技术栈、UI或范围冲突时立即停止，不用时间压力作为擅自决定理由。

## 2. 任务表

### T01｜项目盘点与差异检查【用户验收点】

只读检查：

- 根目录和全部 `AGENTS.md`。
- Git 状态和用户已有修改。
- 移动端、服务端、管理端技术栈。
- 启动、构建和测试命令。
- 公共导航、城市、天气、消息、客服、网络、路由、设计系统。
- 是否已有巡检目录、服务目录、位置、媒体资源。
- 与本开发包的冲突。

不得编码。输出拟改文件、路由、接口和表。

### T02｜模块边界与契约映射

- 把本开发包目录映射到现有项目。
- 确认页面编号和路由。
- 确认公共能力复用点。
- 确认 API 响应信封、分页和错误码。
- 更新模块内 README/ADR。

不创建页面大段实现。

### T03｜移动端骨架与真实入口

- 建立 inspection 功能模块。
- 建立 `public.ts` 和宿主动作端口。
- 注册 M01、M02 路由。
- 打通底部“服务”→“我要巡检”真实点击。
- 建立严格类型和空页面状态。

验证：真实入口 E2E 冒烟。

### T04｜M01 上半屏

- 公共顶部复用。
- 搜索框。
- 服务类型 Tab 选中态。
- Hero。
- 场景宫格。
- 320–430宽适配。

仅使用明确的开发 Fixture 验证布局。

### T05｜M01 下半屏与状态【用户验收点】

- 服务保障。
- 热门巡检服务。
- 服务流程。
- 加载、局部失败、整页错误和重试。
- 分类、搜索、更多、查看全部进入 M02。
- M01 视觉截图。

完成后停止，用户验收 M01。

### T06｜M02 顶部、搜索与分类

- 子页面头部。
- 搜索。
- 筛选触发。
- 分类胶囊。
- 城市。
- 返回恢复。

### T07｜M02 排序、筛选与卡片

- 综合、距离、价格排序视图。
- 筛选 bottom sheet。
- 服务卡。
- 统一价格组件。
- 评分/次数空值隐藏。
- 超范围动作端口。

### T08｜M02 列表状态与分页【用户验收点】

- 首次加载骨架。
- 空城市、空筛选、网络错误、超时。
- 下拉刷新。
- 上拉分页和去重。
- 旧请求竞态。
- M02 视觉截图。

完成后停止，用户验收 M02 静态与交互。

### T09｜PostgreSQL/PostGIS 迁移

- 启用/校验 PostGIS。
- 建立分类、服务、城市、标签、入口配置、覆盖范围。
- 建立约束与索引。
- 开发/测试种子数据分离。
- 空库迁移测试。

不得写入生产示例评分、服务次数和价格。

### T10｜目录只读 API【用户验收点】

- `/portal`。
- `/filters`。
- `/services`。
- 参数校验、分页、排序、搜索和空间距离。
- Redis/媒体适配。
- OpenAPI 和服务端测试。

完成后停止，用户验收 API 与数据模型。

### T11｜移动端真实 API 联调

- 移除生产 Mock 引用。
- Portal、筛选、列表接入真实 API。
- DTO mapper。
- 状态缓存和刷新。
- 错误码映射。
- 功能开关。

### T12｜自动化、视觉与性能

- 单元、组件、集成和 E2E。
- 从底部服务真实点击。
- 320/360/375/390/430布局。
- 性能测量。
- 视觉差异清单。

### T13｜Android 真机

- 安装、冷启动、键盘、返回。
- 定位权限。
- 弱网和断网恢复。
- 截图/录屏和问题修复。

### T14｜iOS 真机与交付【用户验收点】

- iOS 安装、安全区、返回手势、键盘、定位。
- 交付构建和测试记录。
- 模块 README。
- API、迁移、回滚说明。
- 已完成/未完成/下一增量清单。

完成后只能标记“巡检目录 I1 完成”。

## 3. 禁止合并任务

Codex 不得把下列事项合并成“一次性完成”：

- T01 与任何编码任务。
- M01 用户验收与 M02 开发。
- 静态 UI 与真实 API 完成声明。
- Android 模拟器与 iOS 真机验收。
- I1 与服务详情/需求发布。

## 4. 每个任务的结束问题

Codex 在结束时必须明确问：

> 请验收当前任务。如果确认通过，请回复“验收通过，继续 Txx”。

不得自行在后台继续下一任务。
