## 1. 登录与账号

1. 需要登录的操作（预约、报名、下单、收藏、评论等）会先进登录页 `/pages/service/inspection/login`，输入**用户名和密码**，勾选同意用户协议和隐私政策后登录；登录成功回到原来要去的页面。
2. 登录后约 15 分钟访问令牌到期，App 自动用刷新令牌续期，不用重新登录；在“我的 → 设置”里“退出登录”会撤销这次登录。
3. “我的”页顶部显示显示名和所属组织（来自 `GET /api/v1/auth/me`，不显示登录名、手机号）。

**未做 / 待定**：

- **没有注册入口**：账号现在只能由平台建（企业客户和机构账号在运营端“机构与资质”里建，见运营操作手册 §2.2）；个人用户自助注册、手机号验证码登录、更换手机号、登录设备、注销账户（15 天冷静期）、个人信息导出都未做（计划 08 S5-8，默认决定是“做”，本分支未合入）。
- 首次启动引导页（Onboarding）未做。
- 企业组织与成员、“切换企业身份”未做（计划 08 S5-7，本分支未合入）。

## 2. 首页

底栏五项：**首页 / 发现 / 消息 / 购物车 / 我的**。

首页顶部是城市 + 频道行：**推荐 / 专业服务 / 赛事研学 / 体验 / 商城**，下面是常驻搜索框。

- **切换城市**：点左上角城市，城市面板分“已开通”“筹备中”两组（运营端维护），也可以搜索全国地级市。选“筹备中”的城市时只能先浏览全国商品与线上体验。城市未开通首页（`PLACES` 开关）只在预览构建。
- **推荐频道**：金刚位（无人机、机器人、趣玩挑战、设备租赁、培训课程、赛事报名、研学体验、线下场馆）、两张大卡“找专业服务”“去体验”、下半部分的推荐聚合（赛事研学、商城、场馆、城市资讯）。公开构建里只有通往巡检的入口；轮播、推荐聚合、扫一扫按钮只在预览构建。
- **专业服务频道**：页签“巡检 / 航拍 / 测绘 / 设备维护 / 技术支持”。巡检公开；其余四个页签 [预览：PROSERVICE]。
- 公开构建的首页搜索框只搜巡检；预览构建里除“专业服务”频道外的搜索框进全局搜索（§15），专业服务频道仍搜巡检。

## 3. 巡检服务（公开）

完整路径：首页 → 专业服务 → 巡检 → 目录 → 详情 → 登录 → 预约 → 方案确认 →（付款）→ 履约 → 报告交付与验收 → 订单。

1. **找服务**：在“巡检”页点场景（电力、油气、光伏等）、热门服务、“查看全部”或搜索，进入巡检服务目录。目录可搜索、切分类、排序（综合 / 距离最近 / 价格）、筛选、切城市、下拉刷新、上拉翻页。距离排序要允许定位，拒绝时退回综合排序。
2. **看详情**：服务、服务商（“资质已审核”只在平台审核过时显示）、计价与取消说明、流程、交付物、保障。评分和服务次数只有真实数据时显示。
3. **预约**：点“立即预约”（没登录先登录）→ 填联系人、巡检地点（预览构建可以用地图选点，现为本机模拟地图）、期望时间段、巡检项目、附件（JPEG / PNG / PDF）→ 提交。提交不产生费用。提交结果页可以在规则允许时取消预约。
4. **确认方案**：服务商出方案后，“消息”里有“服务进度”通知。进方案确认页看版本、报价明细、交付约定，点确认。
5. **付款（巡检付款节点）**：只有后端打开 `INSPECTION_PAYMENT_NODES_ENABLED` 时方案才带付款节点：确认后先付首付 30%（经收银台，微信支付，钱进服务商自己的商户号），首付到账后服务商才开始安排；之后每次验收后付这一次的服务费。开关关着时没有付款步骤。收银台属于 `TRADE` 开关，公开构建现在关着。
6. **看履约**：服务安排页显示服务团队（含“持证飞手 N 名”）、设备和每次巡检的排期、进度。
7. **改期**：每次巡检开始前 24 小时之前可以申请改期，服务商确认后生效。
8. **验收**：每次巡检交付后进报告交付页，下载交付文件（短时链接）、确认验收；不满意可以“退回整改”并写原因，服务商重新交付后再验收（不自动退款）。
9. **取消**：第 1 次巡检开始前可以在线取消；没付首付的不收费，付了的整笔原路退回。巡检开始后不能在线取消，联系客服协商（平台只协助沟通）。
10. **查订单**：“我的 → 订单”或 `/pages/mine/inspection-orders` 按状态查看，点进对应的方案、履约或交付页。

## 4. 四类专业服务、需求发布与服务订单 [预览：PROSERVICE、DEMAND、SERVICE_ORDER]

1. **看服务**：专业服务频道的航拍、测绘、设备维护、技术支持页签 → 服务目录（搜索、筛选、价格排序）→ 服务详情 → 服务商主页（经营主体、服务方式、授权有效期等只显示平台审核通过的一版）。
2. **发布需求**：服务详情主按钮“发布需求”，或专业服务频道的“发布需求”条 → 选类型（巡检、航拍、测绘、设备维护、技术支持）→ 填需求（可存草稿）→ 提交。附件上传未做。
3. **收报价**：平台匹配或邀请 1–3 家服务商，72 小时报价期；“消息”里有“需求与报价”通知。“我的 → 需求与报价”看全部需求单、询价单、租赁询价单。
4. **比选**：报价比选页和方案对比页（服务团队、夜间作业、报告时效、影像存档、首次进场日期、报价明细）→ 选定一家。选定不产生费用。
5. **服务订单**（四类服务选定后自动生成；巡检类需求停在“选定”）：服务商出方案（金额等于报价）→ 客户在方案确认页确认 → 一次付清（每次付款 15 分钟有效）→ 服务商开工 → 交付（交付说明和文件，文件经 10 分钟链接下载）→ 客户验收或退回整改。
6. **取消**：开工前客户或服务商都能取消，已付款整笔原路退；开工后走客服协商，由服务商在工作台“协商终止”并填退款金额。

## 5. 商城：浏览、购物车、下单、收货、售后 [预览：MALL、CART、TRADE]

1. **浏览**：首页“商城”频道，类目页签“无人机 / 机器人 / 配件 / 租赁 / 课程”，可搜索、筛选（体验方式、交易方式、经营商家、价格区间）、价格排序。
2. **商品详情**：图集、卖点、在售商家（标出能否在线付款、开票方、售后责任方）、规格与数量、参数、包装清单、图文介绍；“先体验，再决定”（有关联体验时）、“相关内容”、“售后与保障”；“查看商家主页与资质”进商家主页（在售 / 活动 / 内容 / 资质）。
3. **加入购物车**：只有标价的“购买”商品能进购物车（租赁、询价商品不进）。底栏“购物车”按商家分组，可改数量、管理删除、清理失效商品。一次只能结算一个商家。
4. **确认订单**：选配送方式（快递 / 到店自提）、收货地址（“我的 → 收货地址”，手机号打码显示）→ 提交订单。商家没登记收款账户时提示“暂未开通在线支付”，不能提交。
5. **付款**：收银台用微信支付（App 支付）；**未付款 30 分钟后自动关闭**。付款结果只以服务端收到的微信回执或查单为准。
6. **收货**：快递单在“商品订单”详情看物流；自提单凭 6 位取货码到店核销。发货 10 天后自动确认收货，也可以手动确认收货。
7. **取消与退款**：已付款未发货可以自己取消，全额原路退款；发货后的退款由商家在工作台发起（可部分）。
8. **售后**：商品订单详情 → “申请售后”：
   - 仅退款：已付款未发货时，申请即全额退款，不用商家同意。
   - 退货退款：七天无理由（商品没标“不支持七天无理由”，确认收货起 7 天内）或质量问题（确认收货起 15 天内），可上传凭证图片（每格 ≤3 张、共 ≤9 张）→ 商家同意并给寄回地址 → 填退货运单 → 商家确认收货并退款（可少退，需写说明）或验货不通过。
   - 商家 48 小时不处理自动同意；同意后 7 天不填运单自动关闭；寄回后 10 天商家不处理按申请金额自动退款。协商不成可联系平台客服（平台只协助沟通、不裁决）。
   - “我的 → 退款/售后”看全部售后单。
9. **对比**：商城卡片的“对比”和商品对比页 [预览：FAVORITE]，对比只在本机做。

## 6. 询价商品 [预览：MALL、TRADE]

1. 交易方式为“询价”的商品，详情点“联系询价”→ 填询价单：配置和用途（≤200 字）、数量 1–99、期望交付日期、选 1–3 家商家 → 提交（不产生费用）。
2. 72 小时内收报价，截止时一家都没报的自动关闭。
3. 报价比选页按综合 / 总价 / 交期排序 → 选定一份（其余失效）。
4. 按报价进确认订单（数量、单价锁定，不能改）→ 提交 → 收银台付款。之后和普通商城订单一样。

## 7. 设备租赁 [预览：RENTAL、TRADE]

1. 交易方式为“租赁”的商品，详情点“联系询价”→ 租赁询价单：台数 1–10、起租日（不早于明天）、天数 1–90、使用地点（从收货地址选）、交接方式、归还方式、补充说明 → 提交（不产生费用）。7 天内没有报价自动关闭。
2. 商家报价后进租赁报价单，核对租期、费用和合同条款，勾选后“确认合同” → 收银台一次付清租金（30 分钟内付款）。押金不在线收取。
3. 商家录入交接后，在租赁订单页“确认交接”（从此计租）；商家录入归还后“确认归还”，订单结束。有异议不要确认，联系商家。
4. 合同详情页可以看合同信息；合同文件、交接照片未做。付款后客户不能自己取消，交接前商家可以取消并全额退款。
5. “我的 → 租赁订单”查看。

## 8. 赛事研学：活动报名 [预览：ACTIVITY]

1. **找活动**：首页“赛事研学”频道（赛事、培训、研学、体验日），或金刚位“赛事报名”“研学体验” → 活动详情（场次、报名状态、报名须知）。
2. **参与人**：“我的 → 参与人管理”添加本人、子女（只收姓名和出生年月，不收证件号和手机号）。未成年人由监护人账号代报。
3. **个人报名**：选场次 → 填写报名（选一人或多人、勾选监护人确认和报名须知）→ 免费活动提交即成功；收费活动进收银台，**15 分钟内付款**，超时名额释放。成功后每人一张报名凭证（一人一码）。
4. **候补**：场次满员且允许候补时，可以“加入候补”（1–10 人，不收费，可随时放弃）。有名额时按排队顺序转正，转正保留 15 分钟：免费的点“确认报名”，收费的点“去付款”；过时作废给下一位。消息里有“候补转正”通知。
5. **团队报名**：领队代报 2–20 人，填团队名称、领队姓名和手机（只给领队本人看，打码显示）、队员名单（可选已有子女或现填，支持粘贴名单），提交前逐行核对 → 收费的领队一次付清。团队报名不能候补。
6. **退改**：报名凭证或订单页 → “申请退改”：
   - 取消：开场前按人勾选，收费的每人按单价原路退款，提交即退；
   - 改期：开场前把整张报名单改到同一活动另一个有名额的场次，立即生效，旧码作废、发新码，不补差价。
   - 退改详情页看退款进度（提交 → 退款中 → 已到账）或改期结果。
7. **签到与结果**：到场出示凭证，主办方用 App“工作模式”核销（§14）。主办方录入结果后，凭证和结果页显示完成情况、成绩和证书说明，“消息”里有“结果已发布”。
8. **查看**：“我的 → 活动报名”（候补卡、团队卡、已结束的“查看结果”、已取消的“查看进度”）。
9. 未做：主办方发起的活动延期 / 取消、完赛证明 PDF、只改其中一人的改期、活动开始前的定时提醒。监护人确认和报名须知的协议正文尚未提供。

## 9. 体验：到馆预约与线上体验 [预览：EXPERIENCE]

**到馆预约**

1. 首页“体验”频道、大卡“去体验”或金刚位“线下场馆” → 场馆详情（营业时间、检票规则、项目、馆内设备）→ 选项目和场次。
2. 确认到馆预约：选参与人（和活动共用名单，一单最多 10 人）→ 标价为 0 的提交即成功；收费的进收银台，**15 分钟内付款**。
3. 成功后得到一个核销码（一单一码，`/pages/venue/booking`），到馆出示，场馆操作员核销（开场前 30 分钟到场次结束）。
4. 开场前可以改期（同项目另一场次，旧码作废换新码）或取消（整单原路全额退款）。场次结束没到馆的变“已过期”，不退款。
5. “我的 → 体验预约”查看。

**线上体验**

1. 体验频道的线上体验项目：**虚拟仿真**两个任务模板（无人机起降与悬停、机器人避障），在 App 内完成，结束后看体验结果；**软件试用**、**课程试听**按项目的试用时长开始。
2. “我的 → 体验记录”看本账号的记录。不接外部仿真平台。

## 10. 课程 [预览：COURSE、MALL、TRADE]

1. 金刚位“培训课程”或商城“课程”页签 → 课程列表（子类目、综合 / 价格排序）→ 课程详情（章节目录、开通方式、退款规则）。
2. **先试听**：试听课时不用登录、不记进度。
3. **报名**：只有“单人账号”一种规格 → 收银台付款（15 分钟内）→ 付款到账即开通。
4. **学习**：“我的 → 我的课程” → 课程学习页，播放一节记“开始”、播完记“学完”。第一次开始非试听课时前会弹窗提醒：开始后不能在线退款。
5. **退款**：自己买的、付款后 7 天内、还没开始学非试听课时，课程学习页“申请退款”全额原路退回；其余联系客服。
6. 线下班卡片点进对应的活动报名（§8）。购买商城商品附带的课程，在商品订单完成后自动开通。
7. 未做：课程评价、证书、家庭 / 企业多人账号、离线下载、倍速与续播；课程订单不在“我的订单”合并页里。

## 11. 发现 [预览：CONTENT、LIVE]

公开构建的发现页保持原样（M19、M20 都只在预览构建）。

1. **频道**：推荐 / 视频 / 直播 / 赛事 / 研学 / 案例 / 知识。赛事、研学直接列真实活动。
2. **图文与专题**：案例、知识图文详情里的“内容中提到”可以点进对应的商品、服务、活动、场馆页面；专题页列活动、场馆和图文。
3. **视频**：视频频道或推荐里的视频卡 → 视频详情或竖屏视频流（上下切换）。登录后可点赞、关注发布机构、评论（≤200 字）、举报评论。
4. **直播** [LIVE]：直播频道或直播条 → 直播预告（可设提醒，开播时“消息”里有“直播提醒”；有回看链接时可看回看）→ 直播间：画面、弹幕（登录后发，≤50 字）、点赞、关注主办机构、讲解清单（点进平台内详情页下单）、举报弹幕、上下切换。直播间不收款、不打赏。

## 14. 工作模式：扫码 / 输码核销（机构操作员）

只给活动主办或承办机构、场馆运营机构的操作员账号（服务端判断）；`ACTIVITY` 或 `EXPERIENCE` 任一打开才出现。

1. “我的 → 工作模式”进核销工作台：看本机构今天的场次（未开放 / 核销中 / 已结束、应到人数）。
2. 点“扫码核销”用相机扫凭证（H5 浏览器里不能调相机，改为手动输入），或直接输入凭证号：`ACT-` 开头是活动凭证（一人一码），`VEN-` 开头是到馆核销码（一单一码，整单核销）。
3. 结果：核销成功；或被拦下（非本机构、已取消、未付款、重复、已过期、场次不符），被拦下的会记一条。
4. “核销记录”只看本人的记录；被拦下的记录可以在“核销异常处理”里登记一次：场次不符或过期的可“不予核销”，同一活动 / 项目另一场正在核销且有余位时可“放行”（要勾选已人工核验身份）；其余只能“拦截”。
5. 核销员名单就是机构的操作员账号（运营端“机构与资质”里建），没有单独的核销员名单页。
