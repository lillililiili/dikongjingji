# 02｜两页 UI 开发规格

## 1. 参考图使用原则

参考图：

- `references/ui-01-inspection-entry.png`
- `references/ui-02-inspection-catalog.png`

仅用于确认视觉风格、内容层级和组件关系。禁止：

- 将整张参考图作为背景。
- 依照原图像素写死页面。
- 从图中裁切文字、按钮、价格作为交互控件。
- 为塞下所有内容而缩小字体和触控区。
- 将示例城市、天气、价格、评分和服务次数写死。

以 375 逻辑像素宽度为主要还原基准，同时验证 320、360、390、412、430。超过 600 时主体最大宽度 600 并居中。

| 内容 | 建议 |

## 3. INS-M-002：我要巡检入口

### 3.1 页面职责

- 展示当前城市和巡检入口。
- 展示场景分类。
- 展示服务保障。
- 展示热门服务。
- 展示服务流程。
- 把搜索、分类、“更多”和“查看全部”导向 INS-M-003。

不得在此页直接创建需求、生成订单或模拟咨询。

### 3.2 组件结构

```text
InspectionPortalPage
├── PublicServiceHeader
│   ├── CurrentCityTrigger
│   ├── WeatherSummary
│   ├── InspectionSearchBar
│   └── MessageEntry
├── PublicServiceTypeTabs
├── InspectionHero
├── InspectionCategoryGrid
├── InspectionGuaranteeStrip
├── HotInspectionServices
├── InspectionProcess
└── PublicAppTabBar
```

城市、天气、消息、顶部服务分类和底部导航优先复用公共组件。

### 3.3 区域规格

| 区域 | 内容 | 数据来源 | 交互 |
| --- | --- | --- | --- |
| 城市 | 当前城市、可选天气 | 公共城市/天气 | 调公共城市选择 |
| 搜索 | 服务、场景或关键词 | 本地输入 | 提交进入 M02 |
| 消息 | 图标、真实未读数 | 公共消息 | 调消息入口 |
| 服务类型 | 航拍、巡检、飞无人机、机器人、更多 | 公共配置 | 巡检处于选中 |
| Hero | 主标题、说明、保障点、图片 | 入口配置 API | 主按钮走宿主端口 |
| 场景宫格 | 8个入口 | 分类 API | 分类进入 M02 |
| 保障 | 资质、设备、报告、售后 | 入口配置 API | 默认展示 |
| 热门服务 | 卡片摘要 | 入口配置/API | 查看全部进入 M02 |
| 流程 | 4步说明 | 入口配置 API | 默认展示 |

### 3.4 Hero

- 宽高比约 2.7:1，响应高度 128–152dp。
- 图片使用独立可商用资源。
- 文字区保持可读，必要时使用浅色遮罩。
- 图片失败时使用浅蓝背景和巡检图标，文字及操作仍可用。
- 主按钮触控高度至少 44dp。
- 发布需求能力未接入时，生产功能开关隐藏主按钮。

### 3.5 场景宫格

默认编码：

| 编码 | 默认名称 | 副标题示例 |
| --- | --- | --- |
| POWER | 电力巡检 | 线路·杆塔·变电站 |
| PHOTOVOLTAIC | 光伏巡检 | 热斑·组件·效率 |
| OIL_GAS | 油气巡检 | 管线·泄漏·安全 |
| THERMAL | 热力巡检 | 热成像·管网评估 |
| PARK | 园区巡检 | 安防·设备·环境 |
| EQUIPMENT | 设备巡检 | 状态·故障·记录 |
| PERIODIC | 定期巡检 | 周期计划·持续跟踪 |
| MORE | 更多场景 | 按需求定制方案 |

规则：

- 四列两行。
- 320宽可缩小间距，不得竖排文字。
- 图标、名称、副标题、顺序来自配置。
- 不以数组下标或中文名称进行业务判断。
- `MORE` 进入 M02 并首次打开筛选层。

### 3.6 服务保障

- 设计为横向浅色条，不做四张相同大卡。
- 360 及以上可四项展示；更窄时横向滚动。
- 无真实配置时整体隐藏。
- 不创建假跳转。

### 3.7 热门服务

- 使用横向滚动卡片，不强压固定四列。
- 卡宽建议 `clamp(152dp, 44vw, 180dp)`。
- 图片比例约 4:3。
- 标题最多两行。
- 只展示一个主要标签。
- 价格由统一组件渲染。
- 评分或服务次数为空时不展示。
- 无数据时隐藏整个区块。

### 3.8 服务流程

- 四步：提交需求、方案报价、现场执行、报告验收。
- 本期为解释性内容，不表示后续功能已完成。
- “了解详情”未接入时生产隐藏。

## 4. INS-M-003：巡检服务列表

### 4.1 页面职责

- 展示当前城市的巡检服务。
- 关键词搜索。
- 分类、高级筛选。
- 综合、距离、价格排序。
- 下拉刷新和上拉分页。
- 把详情、咨询、预约交由宿主端口处理。

### 4.2 组件结构

```text
InspectionCatalogPage
├── SubPageHeader
│   ├── BackButton
│   ├── PageTitle
│   └── CustomerServiceEntry
├── CatalogSearchRow
│   ├── CatalogSearchBar
│   └── FilterTrigger
├── InspectionCategoryChips
├── InspectionSortBar
├── CatalogStatePanel
│   ├── InspectionServiceCard[]
│   ├── CatalogSkeleton
│   ├── CatalogEmpty
│   ├── CatalogError
│   └── LoadMoreState
├── InspectionFilterSheet
└── PublicAppTabBar
```

### 4.3 顶部导航

- 返回触控区至少 44×44dp。
- 标题固定“巡检服务”。
- 客服按钮调用公共能力。
- 客服未接入时生产隐藏，不进入空白页。
- 底部“服务”继续选中，遵循参考图。

### 4.4 搜索

- 高度 44dp。
- 中文输入法组词期间不发查询。
- 键盘搜索键提交。
- 可在停止输入 300ms 后查询，但路由历史不得每个字符新增一条。
- 新搜索取消或忽略旧请求。
- 清空后保留城市、分类和已应用筛选。
- 前后空格清理，长度最大 50 字符。

### 4.5 分类胶囊

默认：

```text
全部｜电力｜热力｜油气｜光伏｜园区
```

- 横向滚动，不换行。
- 单选。
- 选中项橙底白字。
- 切换后重置分页，保留城市和关键词。
- 当前城市无该分类时展示明确空状态。

### 4.6 排序栏

| 排序 | 行为 |
| --- | --- |
| 综合排序 | 默认，平台权重后以服务 ID 稳定排序 |
| 距离最近 | 获得位置权限后按距离升序 |
| 价格 | 第一次升序，再次降序 |
| 当前城市 | 调公共城市选择并重新查询 |

距离排序：

- 需真实位置和服务覆盖数据。
- 未授权时解释权限用途。
- 拒绝后保持原排序，普通浏览不受影响。
- 不得自行混用 GCJ-02/WGS84。
- 定位中显示局部状态，不阻塞整页。

### 4.7 高级筛选

bottom sheet，不新增页面。字段只以服务端支持为准，首期建议：

- 服务方式：现场巡检、周期巡检、定制方案。
- 可用状态：当前可服务、可预约。
- 价格类型：按次、按公里、按项目报价。
- 是否包含报告。

规则：

- 最大高度 80vh，适配底部安全区。
- 打开时复制已应用条件为临时草稿。
- 确认后应用。
- 遮罩/取消不修改已应用条件。
- 重置不清空城市和关键词。
- 已选数量展示在筛选按钮。

### 4.8 服务卡片

```text
┌────────────┬─────────────────────┐
│ 场景图片    │ 标题                │
│ 分类角标    │ 摘要                │
│            │ 能力标签             │
│            │ 价格/评分/服务次数    │
│            │              主动作 │
└────────────┴─────────────────────┘
```

规则：

- 单列，卡片宽度占满内容区。
- 最小高度 148dp，内容增加时自动增高。
- 左图宽 `clamp(112dp, 35vw, 136dp)`，比例 4:3 或由资源元数据稳定占位。
- 右侧容器设置 `min-width: 0`，防止长标题撑出屏幕。
- 标题、摘要最多两行。
- 标签最多三项，可换行。
- 主动作至少 88×44dp。
- 价格和统计空间不足时可分两行，禁止挤成竖排。

价格模式：

```text
STARTING_PRICE
PER_DISTANCE
PER_VISIT
PROJECT_QUOTE
```

`PROJECT_QUOTE` 只显示“按项目报价”，不得显示虚构起步价。

### 4.9 刷新与分页

- 支持下拉刷新。
- 距底部约 80dp 时触发下一页。
- 同一页只允许一个加载任务。
- 按服务 ID 去重。
- 末页展示“没有更多了”。
- 条件变化后页码重置。
- 刷新失败保留旧数据，并提示刷新失败。
- 初次加载失败展示整页错误和重试。

## 5. 页面状态

### M01

```text
INITIAL → LOADING → READY
                  ├→ PARTIAL_ERROR
                  └→ ERROR
```

- Header 保持稳定。
- 单个区块失败时局部重试。
- 无当前城市时提示选择城市，不展示其他城市价格。

### M02

```text
INITIAL_LOADING
READY
REFRESHING
LOADING_MORE
EMPTY_CITY
EMPTY_FILTER
OFFLINE
ERROR
LOCATION_DENIED
UNAUTHORIZED
SESSION_EXPIRED
```

关键口径：

- `EMPTY_CITY` 提供切换城市。
- `EMPTY_FILTER` 提供清除筛选。
- `OFFLINE` 可显示最近一次非敏感缓存，但明确标记。
- `LOCATION_DENIED` 只影响距离排序。
- 目录浏览默认可匿名；需登录的后续动作再触发登录。

## 6. 无障碍与真机

- 所有图标按钮有可读标签。
- 分类不能只靠颜色区分。
- 图片有语义化 alt。
- 文本放大 130% 不裁切；150% 允许卡片增高。
- Android 返回键、iOS 返回手势与顶部返回一致。
- 键盘不遮挡搜索操作。
- iPhone 底部安全区不遮挡最后一项。
- 最后内容增加 `TabBar 高度 + safe-area` 的底部内边距。
